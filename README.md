# Portfolio Admin

This folder is a standalone GitHub Pages site for the private portfolio editor.

## Deploy separately

Copy the contents of this folder into a separate GitHub repository such as `Iqram-portfolio-admin`. Keep `.github/workflows/deploy-pages.yml`, then enable **Settings > Pages > GitHub Actions** in that repository.

The editor requires the Supabase URL, publishable key, database schema, and an owner account. See the main repository's `DEPLOYMENT.md` for the complete setup.
